AEI CONTROL — AMERICAN ENGINEERING INC.
==========================================

ESTRUCTURA:
- index.html      Interfaz completa de AEI Control.
- logo.jpg        Logo original proporcionado por el usuario.
- manifest.json   Configuración de aplicación instalable/PWA.
- sw.js           Service Worker para carga y funcionamiento offline básico.
- README.txt      Estas instrucciones.

INSTALACIÓN DESDE CERO EN GITHUB:
1. Crea un repositorio nuevo. Ejemplo: aei-control
2. Sube TODOS estos archivos a la raíz del repositorio.
3. Ve a Settings > Pages.
4. En Build and deployment selecciona "Deploy from a branch".
5. Selecciona la rama principal (main) y carpeta "/ (root)".
6. Guarda.
7. Espera a que GitHub Pages publique la página.
8. Abre la dirección que GitHub te entregue.

IMPORTANTE:
No cambies los nombres de los archivos.
Los cuatro archivos principales deben quedar juntos en la misma carpeta.

NOTA:
El dashboard es una base visual y funcional inicial. Los módulos de Máquinas,
Producción, Alertas, Reportes y Configuración están preparados para que los
conectemos después a datos reales sin tener que rehacer la interfaz.
